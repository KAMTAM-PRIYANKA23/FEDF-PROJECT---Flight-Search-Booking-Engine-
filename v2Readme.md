# SkyWings Airlines Booking System – Version 2

## Module Implemented

### User Dashboard

This version extends the User Authentication module by introducing a User Dashboard that acts as the central hub for passengers after login.

---

## Features Implemented

### New Booking

* Access flight booking services
* Navigate to booking-related pages

### Booking History

* View previously booked flights
* Track travel records

### Cancel Booking

* Manage and cancel existing reservations

### Notifications

* View important updates and travel alerts
* Receive booking-related information

### User Dashboard Interface

* Personalized dashboard layout
* Easy navigation to all user services
