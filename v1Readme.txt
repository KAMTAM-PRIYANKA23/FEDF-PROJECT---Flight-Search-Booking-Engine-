# SkyWings Airlines Booking System - Version 1

## Module Implemented

User Authentication

### Features

* User Login
* User Signup
* Navigation Protection
* Authentication Routing

### Technologies Used

* React.js
* TypeScript
* Vite
* React Router

### Run Project

```bash
npm install
npm run dev
```

### Description

This is Version 1 of the SkyWings Airlines Booking System. It implements the User Authentication module, allowing users to register and login before accessing other system features.

Future modules such as Dashboard, Flight Search, Booking, Payment, and Admin Management will be implemented in subsequent versions.
